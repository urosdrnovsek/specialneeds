# Course and player refinement

The three longer pilot courses now use four expandable stage panels. The stage containing the first unexplored activity opens by default. Each stage shows an explored count; all16 activity placements remain directly available. Rows show a purpose, explored marker and whether the activity is interactive, adult-read picture play or shared offline practice. Start/Continue remains a direct action and no course stage is mandatory.

Adults can choose automatic/manual pacing on a course page. The shared player exposes the same setting alongside Pause and Finish for now. Switching modes keeps the task and completed placements. Turning automatic progression off cancels pending reading and quick-play transitions. Switching it on after a completed reading task schedules the next round; a paused task stays paused.

Pilot activity purpose and adult adaptations are consolidated into one panel beneath the game, while the existing current-word teaching cues remain available. Cached authored panel content prevents repeated replacement of the notes; an opened panel stays open during control refreshes.

Verification includes automatic/manual studio tests, all48 pilot launches, first-unexplored-stage selection, retained activity access, live pacing changes, pause cancellation, shared offline continuation, single-panel notes and retained open state. Existing reading regressions and purposeful-game checks pass. Browser/device visual and physical gesture sign-off remains pending under the current Sites preview limitations.
