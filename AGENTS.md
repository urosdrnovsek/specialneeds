# Activity quality and retired implementations

The user explicitly retired picture-only reveals and topic selectors that end without doing anything with the choice. Do not restore their old implementations, including through legacy routes, saved progress, or another title.

Retired activity implementations: Make Something Happen; Meet a New Word; My Favourite Adventure; Choose Our Activity; Show Me Your Choice; Describe Without Saying; Choose Your Adventure; Comfortable Controls; Direct the Adventure.

Their existing positions now use four shared games: Duck’s Canal Rescue, The Toy Bus Repair Shop, Marble Machine: Ring the Bell, and The Anywhere Adventure Bus. Reuse across support pathways is intentional; do not advertise those placements as nine different games.

A game needs a clear goal, meaningful actions, visible consequences, and a sensible finish. Repeated clicks that redraw an unchanged object are not a game. A topic choice must open an activity that uses the chosen topic. Keep adult teaching notes and accessible input; never infer reading mastery or treatment benefit from device actions. Preserve tap/keyboard alternatives to dragging, untimed play, and automatic default course progression.

When package.json is present, run `npm run test:purposeful` for changes to these games; also run affected reading/home checks. Otherwise use the equivalent project test fixtures. Preserve the regression checks against retired modes and labels. Follow the session’s supported browser workflow and report unavailable physical-touch/layout verification honestly.

The user additionally requires direct interaction with gameplay objects. Do not replace boarding, carrying, sailing, building or placing objects with a generic button that advances a scripted scene. Duck, cargo, boats and story props must support meaningful tap/select-place and drag paths; pump/gate controls must not automatically finish the rescue.

Artwork quality: audit the shared generators and the complete asset inventory when changing illustrations. Spatial words must match surface contact and occlusion; sitting/sleeping figures need support; hands and props must meet with consistent limb proportions. Preserve native icon viewBoxes. Run the art inventory/contact checks and affected interaction suites. Report visual-review coverage separately from automated rendering coverage.
